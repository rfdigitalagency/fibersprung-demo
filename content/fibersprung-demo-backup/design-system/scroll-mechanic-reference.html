Mechanic reference

Pin, scale to full bleed, then let the next section cover it.

Three separate techniques stacked into one move. Scroll slowly and each one separates out: the panel pins itself, the frame grows edge to edge, the copy rises, then the following section slides up over the whole thing.

No libraries. Roughly forty lines of JavaScript driving one CSS transform. The comments in the source explain what each piece does and where it breaks.

The section above is still pinned behind this one.

It never unmounted. The runway ran out of height, so this panel scrolled up over it. The negative top margin and the rounded top edge are what make it read as intentional rather than as a seam.

Scroll back up and the whole sequence reverses cleanly, because the effect is driven by scroll position rather than by one-way triggers.

Things that break this

  • Any ancestor with overflow:hidden kills position:sticky silently. Check this first.
  • Animating width or height instead of transform causes visible stutter on mid-range phones.
  • On phones, scrub scrolling fights the browser's address bar. Better to drop the pin below about 900px and play the reveal once on entry.
  • The effect only works with one genuinely strong image. A mediocre photo enlarged to full screen is a mediocre photo, only bigger.
